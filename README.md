# Colheitas · Manual de teste

Aplicação web (PWA) de apoio à fase pré-analítica, com um manual de colheitas **fictício** (dados de teste — não usar em contexto clínico).

Projeto apresentado às IV Jornadas dos TSDT de Análises Clínicas (ULSSA, 21-nov-2026).

- Funciona offline depois da primeira abertura
- Perfis: Administrativo, Enfermeiro, Técnico, Médico
- Leitura de requisições por fotografia feita no próprio aparelho (a imagem não sai do telemóvel)
